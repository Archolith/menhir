# Code of Conduct

Menhir follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
It applies in this repository's issues, pull requests, discussions and any other project space,
and when someone represents the project in public.

In short: be respectful, assume good faith, keep criticism about the work, and do not harass
anyone. Unwelcome sexual attention, personal attacks, threats and publishing someone's private
information are not acceptable.

## Reporting

Report conduct problems privately to **security@archolith.dev**, the maintainer's contact.
Reports are kept confidential.

## Enforcement

The maintainer reviews each report and may respond, in line with the Covenant's enforcement
guidelines, with a warning, a temporary ban or a permanent ban from project spaces.
